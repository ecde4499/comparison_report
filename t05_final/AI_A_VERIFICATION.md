## 1. 구현 결과 요약

- **글자 수 카운터 UI 추가**: `<textarea id="txt">` 입력란 아래에 실시간 글자 수를 표시하는 `<div id="char-count">` 요소를 추가했습니다.
- **실시간 글자 수 카운팅**: `Intl.Segmenter` API(grapheme 기준)를 사용하여 이모지(😀😀 등), 한글, 영문, 줄바꿈(\n)이 포함된 문자열의 글자 수를 사용자가 인식하는 글자 수 단위 그대로 정확히 카운트합니다.
- **200자 초과 경고 연동**: 200자를 초과할 때 입력이나 Canvas 미리보기를 제한하지 않고, 권장 기준 초과임을 알리는 경고 스타일(핑크색 강조 텍스트 + `(권장 초과)` 문구)을 실시간 적용했습니다.
- **기존 기능 보호**: 기존의 Canvas 미리보기 렌더링, 이미지 업로드, 화면비 변경, PNG/JPEG 다운로드, 템플릿 CRUD, localStorage 연동, JSON 가져오기/내보내기 기능 일체를 변경 없이 유지했습니다.
