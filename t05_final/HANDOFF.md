# HANDOFF

## 1. 목표

기존 '짤·카드 스튜디오' 프로젝트의 정상 동작(이미지 업로드, 화면비 조절, 실시간 미리보기, PNG/JPEG 다운로드, 템플릿 CRUD 및 JSON 내보내기/가져오기 등)을 완벽히 보존하면서, 문구 입력란 아래에 실시간 글자 수 카운터(`현재 글자 수 / 200자`) 및 200자 초과 시 권장 기준 초과 경고 표시 기능을 추가 구현하고 인수인계하는 것입니다.


## 2. 현재 상태

- `index.html` 내 문구 입력 영역 아래에 실시간 글자 수 카운터 UI(`div#char-count`)가 추가되었습니다.
- `Intl.Segmenter` API를 활용하여 이모지, 다국어, 줄바꿈이 포함된 텍스트의 글자 수를 사용자가 인식하는 글자 수 기준으로 정확히 측정하도록 구현되었습니다.
- 200자 초과 시 입력이나 Canvas 실시간 미리보기가 차단되지 않으며, 경고 색상 텍스트 및 안내 문구가 노출됩니다.
- 고정 검사 항목 T05-01 ~ T05-10 모두 PASS 한 상태입니다.
- **시작 버전 ID**: START-T05-A-01 (작업 기록용 버전 ID)
- **종료 버전 ID**: END-T05-A-01 (작업 기록용 버전 ID)


## 3. 실행 명령

별도의 패키지 설치나 빌드 과정이 필요 없는 순수 클라이언트 HTML5 애플리케이션입니다.

- `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 직접 실행합니다.
- 또는 로컬 웹 서버를 실행합니다:
  python -m http.server 8000

## 6. 다음 행동

다음 AI(AI B)는 동일한 10개 검사를 다시 재현하여 검증을 진행합니다.

1. `안녕하세요` 입력 후 `5 / 200자` 확인 (T05-01)
2. 문구 전체 삭제 후 `0 / 200자` 확인 (T05-02)
3. 200자 입력 시 `200 / 200자` 및 경고 스타일 미적용 확인 (T05-03)
4. 201자 입력 시 `201 / 200자` 및 초과 경고 상태 표시 적용 확인 (T05-04)
5. 201자 상태에서 100자로 줄였을 때 경고 해제 확인 (T05-05)
6. `가A1` 입력 시 `3 / 200자` 확인 (T05-06)
7. `😀😀` 이모지 2개 입력 시 `2 / 200자` 확인 (T05-07)
8. `ABC\nDEF` 입력 시 `7 / 200자` 확인 (T05-08)
9. 문구 입력 후 1:1, 4:5, 9:16 화면비 전환 시 문구 및 글자 수 유지 확인 (T05-09)
10. 201자 이상 입력 후 Canvas 실시간 미리보기에 문구가 계속 정상 렌더링되는지 확인 (T05-10)


## 7. 건드리지 말 것

기존 프로젝트의 다음 정상 동작 및 코드는 절대 수정하거나 변경해서는 안 됩니다.

- 이미지 업로드 및 파일 검증 로직 (PNG/JPEG)
- HTML5 Canvas 기반 실시간 미리보기 및 렌더링 함수 (`render`, `crop`, `wrap`)
- 3가지 화면비 계산 및 비율 처리 (`1:1`, `4:5`, `9:16`)
- 문구 크기, 색상, X/Y 위치, 정렬, 줄 간격 조절 기능
- 완성본 PNG / JPEG 파일 저장 기능 (`download`)
- 템플릿 생성/조회/수정/삭제 (CRUD) 및 `localStorage` 저장 기능
- JSON 파일 내보내기/가져오기 기능 및 JSON 스키마 검증 로직
